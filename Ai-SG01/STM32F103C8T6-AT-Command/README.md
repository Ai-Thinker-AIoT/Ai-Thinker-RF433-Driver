# Ai-SG01 (PAN3120) on STM32F103C8T6 — AT Command Firmware

[![中文](https://img.shields.io/badge/中文-README-blue)](README.zh-CN.md)

Factory-style AT command firmware for the Ai-Thinker Ai-SG01 module: it takes AT commands over UART and changes frequency, data rate, power and TX/RX mode on the fly — suitable for fixed-frequency configuration, power measurement, range testing, reliability testing and GPIO tests.

- Module: Ai-SG01 (PAN3120, Panchip Sub-1G transceiver, no RF front end)
- MCU: STM32F103C8T6, HSE 8 MHz → PLL ×9 → 72 MHz
- Project: generated by STM32CubeMX + Keil uVision5 (`ARM-ADS` toolchain), `MDK-ARM/Ai-SG01.uvprojx`
- Debug UART: USART1 = PA9 (TX) / PA10 (RX), 115200-8-N-1
- Firmware version: `V4.18_P1.1.2`

## 2. Pins

| PAN312x signal | STM32F103C8T6 | Note |
|----------------|---------------|------|
| CSN | PA4 | software chip select |
| SCK | PA5 | SPI1_SCK |
| MISO | PA6 | SPI1_MISO |
| MOSI | PA7 | SPI1_MOSI |
| nRST | PB0 | reset, active low |
| DIO8 / IRQ | PB1 | interrupt input |
| other DIO / GPIO | PB10, PB11, PA11, PA12, PB14 | driven via `AT+GPIOMODE` / `AT+GPIOWRITE` / `AT+GPIOREAD` |

USART1: PA9 / PA10. Full pin map: [`Docs/wiring.md`](../../Docs/wiring.md).

## 3. Default RF settings

| Item | Default |
|------|---------|
| Frequency | `490300000` Hz (490.3 MHz) |
| Modulation | 2FSK |
| Data rate | 50 kbps |
| Deviation | 25 kHz for both TX and RX |
| Power tier | `POWER_LDO_0402` + `POWER_20dBm` |
| TX mode | `tx_mode = 2`, 50 ms period |
| Config storage | Flash `0x0800FC00` (last page), CRC protected |

`AT+CONFIGSAVE` writes the settings to Flash, `AT+CONFIGRESET` restores factory defaults.

## 4. AT commands

`AT+HELP` prints the full table. Common entries:

- Link: `AT+RFMODE` (TX/RX), `AT+TXMODE`, `AT+TXSTART` / `AT+TXSTOP`, `AT+TXPERIOD`
- RF: `AT+FREQUENCYBASE`, `AT+DATARATE`, `AT+POWERDBM`, `AT+POWERSELECT`
- Test: `AT+ENTERCARRIER` (CW), `AT+FTMASTER` / `AT+FTSLAVE` (factory master/slave), `AT+CLEARCNT`
- System: `AT+SLEEPMODE` / `AT+WAKEUP`, `AT+RESET`, `AT+GPIOMODE` / `AT+GPIOWRITE` / `AT+GPIOREAD`, `AT+CONFIGSAVE` / `AT+CONFIGRESET`

Per-command details: [`Docs/Ai-SG01-AT-Commands.docx`](../../Docs/Ai-SG01-AT-Commands.docx).

## 5. Build and flash

1. Open `MDK-ARM/Ai-SG01.uvprojx` in Keil uVision5 (Device = `STM32F103C8`, defines `USE_HAL_DRIVER,STM32F103xB`).
2. Rebuild. Create HEX File is enabled; the output is a hex under `MDK-ARM/` (OutputName `at_command_firmware`).
3. Flash with ST-LINK: 3V3 / SWCLK / SWDIO / GND, pin-to-pin on the LoRa-Kit base board.
4. After power-up the UART prints boot info at 115200; send `AT` or `AT+HELP` to confirm the link.

## 6. Notes

- This project is the shared AT framework for Ai-SG01 and Ai-SG01-P; the P variant lives in [`../../Ai-SG01-P/STM32F103C8T6-AT-Command/`](../../Ai-SG01-P/STM32F103C8T6-AT-Command/), differing in the GC1131 front end and the power reporting.
- Hardware: LoRa-Kit V1.0.0 + Ai-SG01 adapter board, pin-to-pin.
- `pull_distance_test_firmware.c` is kept for reference only and is not compiled; swap it in for `at_command_firmware.c` when doing a range test.
