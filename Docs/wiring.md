This file records the module-to-board wiring for the projects under `Ai-SG01/` and `Ai-SG01-P/`, in the same format as `Docs/wiring.md` in the 2.4G repository.

## PAN3120 (Ai-SG01 / Ai-SG01-P)

To be completed — once the projects are imported, list them as "module pin / MCU pin / direction / note".

## General notes

- Supply and ground are common; the module voltage follows its datasheet and must not exceed the rated value.
- To change pins, edit only the port/pin macros at the top of each project's driver header.
